## Runtime and plugin distribution

The executable bundles Python; libc and other system libraries plus both native
agent CLIs remain dependencies. Released Linux binary was built on Ubuntu 22.04;
the local `dist/` artifact used glibc 2.43. Retain the release baseline. A musl
build or Rust rewrite needs a concrete installation requirement and its own tests.

Publish provider-specific skill packages through Git-reference marketplaces.
Catalogs have distinct names `easy1staking-agent-bridge-codex` and
`easy1staking-agent-bridge-claude`; explicit selectors fail closed if a client
chooses the wrong catalog format. Plugin version `0.1.0-alpha.1` corresponds to bridge `0.1.0a1`; bump the plugin
version when its contents change. Initial plugins are skills-only, with no
install hooks, MCP servers, downloads or permission changes. A future explicit,
pinned/checksum-verified binary setup helper can remove bridge PATH setup, but
native CLIs remain required. No global plugin install is performed by this work.
